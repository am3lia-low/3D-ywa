# StoryWorld environment textures

`attic-plaster.webp` is a project-owned wall texture generated with OpenAI's built-in image generation workflow and optimized locally to a 1024 px WebP.

Prompt summary: a seamless, orthographic aged lime-plaster game texture with warm beige variation, fine grain, restrained cracks and neutral diffuse lighting; no objects, perspective, text, borders, watermark or strong baked shadows.
