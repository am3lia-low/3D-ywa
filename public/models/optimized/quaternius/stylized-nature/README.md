# Stylized Nature MegaKit browser subset

This directory contains a deliberately selected and optimized subset of Quaternius' **Stylized Nature MegaKit (Standard)** for the reusable `GhibliWoodlandKit` environment grammar.

- Source: https://quaternius.com/packs/stylizednaturemegakit.html
- Download: https://quaternius.itch.io/stylized-nature-megakit
- Author: Quaternius
- License: CC0 1.0 Universal
- Runtime format: glTF 2.0 / GLB, Y-up
- Texture ceiling: 512 px for this browser build

The raw 99 MB archive is not committed. It remains in the ignored `.asset-cache/` directory. Only the models used by the grammar and their shared, resized textures are shipped.

These assets are presentation-only world dressing. They never mint canonical narrative entities and their deterministic placement is seeded from Part 1's canonical `locationId` plus visual scene semantics.
